About

This project provides a systematic daily study schedule for Maimonides' Sefer HaMitzvos (Book of Commandments). Each event contains the mitzvah number, a concise description, biblical sources when available, and a direct Sefaria link for further learning.

Data & Privacy

Subscribing to the public calendar does not share personal data with us. If you ran the setup script, it uses the Google Calendar API with the single Calendar scope to create the calendar and events in your account. See our Privacy Policy for details.
