Overview

This project provides a public calendar for daily Sefer HaMitzvos study. Subscribing to the calendar does not share personal data with us. If you personally run the setup tool to create a calendar, it requests the minimum Google Calendar scope to create and manage events in your own account.

What data we access

  • Google Calendar API: The tool uses the scope https://www.googleapis.com/auth/calendar to create a calendar named “Sefer HaMitzvos Daily Study” and insert daily study events. It does not read unrelated user data.
  • No backend collection: We do not operate a backend that stores your personal data for calendar subscriptions.
  • WhatsApp (if you opt-in separately): Phone numbers and consent status are used only to deliver requested messages and can be removed anytime by replying STOP.

How we use data

  • Create and update the study calendar and its events.
  • Provide reminder notifications based on your own calendar settings.
  • Support opt-in WhatsApp messages when explicitly requested by you.

Sharing

We do not sell or share personal data with third parties.

Retention

No centralized retention. Calendar data resides in your own Google account. WhatsApp opt-in can be revoked at any time.

Your choices

  • Unsubscribe or hide the calendar in your calendar app at any time.
  • Adjust or disable event notifications in your calendar settings.
  • Revoke Google access at myaccount.google.com/permissions.
  • For WhatsApp messages, reply STOP to unsubscribe.
