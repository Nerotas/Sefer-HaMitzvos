# Bots (Deprecated)

As of October 2025, this repository's WhatsApp bot and related messaging automations are deprecated.

Why:
- Meta/WhatsApp policy treats daily unsolicited messages as spam and disallows this usage.
- Maintaining compliance and sender reputation under these constraints is not feasible for this passion project.

What this means:
- The bot code remains for historical reference but is not supported or recommended for production use.
- Deployment workflows and packaging for the bot are considered legacy.

Alternatives:
- Prefer the public Google Calendar for daily mitzvah reminders.
- Use ICS subscriptions for broad compatibility with calendar apps.
- For 1:1 messaging, consider opt-in flows with clear user consent and low-frequency, user-initiated notifications.

Status:
- Packaging artifacts have been removed from version control (e.g., `mitzvah_bot_lambda.zip`).
- Future cleanups may remove or archive these components entirely.
